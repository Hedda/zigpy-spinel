# zigpy-spinel

This is an experimental software Zigbee stack implemented in Python, using OpenThread RCP as the radio frontend.
A subset of 802.15.4 and the Zigbee APS and NWK layers are implemented.

## ziggurat

This is an even more experimental Zigbee stack implemented in Rust, aiming to emulate a traditional Zigbee coordinator serial interface to be drop-in compatible with existing Zigbee software.
